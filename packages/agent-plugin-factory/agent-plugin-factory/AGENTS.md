# Agent rules
1. Search for an existing MCP/capability before building backend code.
2. Prefer official examples/ext-apps/framework adapters over custom plumbing.
3. Never equate protocol validity with ChatGPT routing quality.
4. Freeze eval corpora before metadata experiments.
5. Real ChatGPT Developer Mode outranks simulator results.
6. Preserve positive and negative cases.
7. Every production failure becomes a regression fixture.
8. Store model/host/date with routing results.
9. Do not republish third-party MCPs without rights review.
10. Optimize for successful useful invocations, not plugin count.
