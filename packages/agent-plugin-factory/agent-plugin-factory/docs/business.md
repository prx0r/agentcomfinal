# Business Model

## Phase 1: Pluginize your MCP
Free readiness scan -> paid conversion/eval/submission-readiness work. The customer is an MCP maintainer who already built domain functionality but has not solved ChatGPT product/routing/review work.

## Phase 2: Managed plugin operations
Recurring routing regressions, conformance changes, metadata tuning, telemetry analysis, security checks and update/submission support. Host/model behavior is non-stationary, so this is recurring value.

## Phase 3: Self-serve factory
```text
paste MCP URL/repo
-> readiness report
-> routing corpus
-> suggested metadata
-> app scaffold plan
-> eval results
-> submission packet
```

## Phase 4: Opportunity miner / owned portfolio
```text
ChatGPT gap -> existing MCP -> plugin -> usage/revenue -> learned ranking model
```

## Rights gate
Allowed statuses:
- owned
- maintainer-authorized
- permissive-license-review-needed
- unknown
- restricted

Do not publicly republish arbitrary MCPs. Code licenses, trademarks, API/data rights and third-party terms are separate issues.

## Strategic dataset
For each plugin store source signal, candidate scores, tool snapshot, metadata variants, intent corpus, simulator results, real ChatGPT results, review findings, publication outcome, invocations, failures, retention and revenue.

Eventually estimate:
```text
P(plugin succeeds | evidence known before launch)
```
