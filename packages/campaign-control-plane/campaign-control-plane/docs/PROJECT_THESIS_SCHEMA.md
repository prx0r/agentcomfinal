
# Project thesis schema

Each project answers:
- What job exists for a real user?
- Why now?
- What is the mechanism, not the feature list?
- What distribution surface reaches existing intent?
- What compounds into a moat?
- What observations would falsify the thesis?
- Which shared primitives are reused?
- What sequence of externally observable behaviors would imply the product exists?

The last question compiles into the checkpoint DAG. A thesis is therefore executable: its claims become tests rather than prose that silently drifts away from the repository.
