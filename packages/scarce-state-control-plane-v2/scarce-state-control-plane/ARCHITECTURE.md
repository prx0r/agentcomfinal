## Ownership boundaries

- **UNDERENGINEER** chooses the shortest credible route to the first moat event.
- **ATask** records goals, tasks, runs, externally validated claims and bounded human decisions.
- **QP/A-COM** owns canonical truth/authority transitions and consequential grants.
- **Seed0** compares successful/failed trajectories and proposes learned policy.
- **Astra/plugin tooling** is downstream manufacturing infrastructure, not the strategic asset.
- **Campaigns** own the hypotheses about real scarce state: authority, customers, transactions, network state, physical observations, etc.

## Non-negotiable rule

Software/code/repo activity can show implementation progress. It cannot increment the scarce asset ledger.
