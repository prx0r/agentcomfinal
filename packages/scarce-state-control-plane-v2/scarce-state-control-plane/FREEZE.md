# Frozen thesis v2 — 2026-09-14

The portfolio is not primarily a set of software businesses and not primarily a plugin factory.

The strategic invariant is:

> **Can OpenAI/platform vendors destroy the value merely by writing more software?**

If yes, demote the reproducible capability to infrastructure. If no, identify the scarce external state that survives: delegated authority, proprietary outcomes, customers, liquidity/network state, trust, physical state/execution, regulated rights, exclusive access, or another resource cognition cannot synthesize.

The objective is:

> **Acquire/produce scarce capability → expose it through whatever agent protocol wins.**

`UNDERENGINEER/1.0` is the portfolio project manager. For each thesis it chooses the earliest real-world event that adds controlled scarce state, then allows only the prerequisites, safety and independent verification needed to reach that event. Feature expansion pauses after the first signal so the next roadmap decision is evidence-driven.

Autonomous construction remains the laboratory: agents compete on minimum-path tasks; ATask records factual runs and human decisions; independent validators establish evidence; QP controls consequential authority; Seed0 learns which trajectories acquire real state more reliably and cheaply.

Software activity, GitHub commits and agent assertions can never increment the scarce-state ledger.
