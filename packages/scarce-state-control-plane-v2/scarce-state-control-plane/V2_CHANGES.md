# v2 changes from Campaign Control Plane v1

1. **Software substitution gate added.** Every project explicitly states what perfect platform software destroys and what external value survives.
2. **Projects separated into asset campaigns vs infrastructure.** Infrastructure is pulled by a live campaign rather than self-prioritized.
3. **Scarce Asset objects + zeroed ledger.** Declarations never count as acquisition.
4. **UNDERENGINEER/1.0 added.** Each project has one first real moat event, a 3–4 step minimum live product, explicit NOT_NOW scope, graduation and kill rule.
5. **Portfolio `order` added.** The top asset campaign emits a concise agent dispatch packet plus the only shared components allowed to be pulled now.
6. **Reward changed.** Business campaigns optimize verified scarce-state gain; infrastructure optimizes scarce-state enablement. Code volume does not score.
7. **Validation trust bug fixed.** `source=live, ok=true` can no longer create `PROVEN`; independently attested evidence at the required class is mandatory.
8. **Evidence ladder added.** Fixture → replay → artifact → active probes → external readback → signed receipt → real economic outcome.
9. **MCP/API scarcity miner ontology added.** Mine the resource behind endpoints, controller/rights, state generation and bypass risk—not wrappers.
10. **GeoDrop restored as an asset campaign** focused on proprietary verified physical installed-base data.
11. **Pogtown underengineered** to agent-generated game packs that humans can play before AR/VR/3D world work.
12. **BreadUp underengineered** to one seller/item/marketplace and a real sale/no-sale outcome before social/multi-market expansion.
