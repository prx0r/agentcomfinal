# MCP / API scarcity miner

Do not ask "which MCP can we wrap?" Ask what scarce resource exists behind the endpoint.

```text
endpoint
  ↓
underlying resource class
  ↓
actual controller
  ↓
provider rights
  ↓
rights we could acquire
  ↓
state generated by usage
  ↓
platform/resource-owner bypass risk
```

Resource classes live in `data/resource_classes.json`.

The important distinction is between the endpoint and the resource. An authenticated banking action may be economically consequential while a generic connector to that bank is still unmoated. Conversely, a provider with exclusive live data or regulated authority may control the scarce asset itself.
