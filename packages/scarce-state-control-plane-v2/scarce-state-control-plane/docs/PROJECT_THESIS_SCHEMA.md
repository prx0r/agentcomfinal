# Project thesis schema v2

Every project must answer two layers.

## 1. Economic survival

- What real user/job exists?
- If OpenAI/platform vendors wrote perfect reproducible software tomorrow, what value disappears?
- What value survives?
- What exact scarce external asset is controlled, by whom, and under what right?
- What event acquires one unit of that asset? What event destroys/decays it?
- Does better AI increase the value of the product, the moat, both, or neither?
- Can the underlying resource owner/platform bypass us?
- What observation falsifies the scarce-asset thesis?

## 2. UNDERENGINEER plan

- What is the earliest real moat event?
- What is the smallest live product that can reach that event?
- Which steps are strictly necessary?
- Which safety/verification boundaries are mandatory?
- What is explicitly NOT NOW?
- What evidence graduates the wedge?
- What evidence kills/rethinks it?
- After first signal, what observation pause occurs before more features?

The full 12-checkpoint DAG remains a capability library. It is **not** the default build order. UNDERENGINEER selects the current minimum experiment.
