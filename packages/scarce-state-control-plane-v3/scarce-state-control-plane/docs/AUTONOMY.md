# Autonomy under the scarce-state objective

Maximum autonomy is not the target. The target is verified scarce-state progress per unit of human attention, money, time and risk.

Tasks remain M/H/A:

- `M` — machine-executable under deterministic policy.
- `H` — bounded human action/judgment is genuinely required.
- `A` — agent action with consequential authority, gated by QP and independent evidence.

UNDERENGINEER controls *what should be attempted*. ATask controls *what is being attempted*. QP controls *what may change consequential state*. Seed0 learns *which successful path should be tried next time*.

Repeated H-tasks are not merely annoyances. They are observations of a structural autonomy bottleneck and should be clustered for later elimination when doing so materially improves the path to scarce-state acquisition.
