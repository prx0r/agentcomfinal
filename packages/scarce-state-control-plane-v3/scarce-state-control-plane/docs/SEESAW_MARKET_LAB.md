# Seesaw Market Lab

Trading is used first as an experimental world, not assumed to be the final business.

## Why

Market prices provide frequent external numeric feedback for the Seesaw chain:

```text
innovation → Δconstraint → Δshadow price → capital allocation → observable outcome
```

## One trial

```text
freeze timestamp
freeze innovation observation
freeze constraint change + sign
freeze affected asset / benchmark
freeze horizon
freeze falsifier
open paper position
wait for resolution
resolve mechanically
score against baseline
append immutable row
```

## What it can validate

- direction/sign accuracy;
- horizon calibration;
- which scarcity classes are predictable;
- whether second-order branches add value;
- which procedures/models improve outcomes.

## What it cannot validate by itself

- live fills;
- slippage;
- borrow availability;
- market impact;
- operational reliability;
- risk-adjusted production trading returns.

Those are separate claims and gates.
