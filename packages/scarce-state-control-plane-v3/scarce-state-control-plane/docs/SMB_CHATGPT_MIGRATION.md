# Free SMB → ChatGPT migration wedge

The UK-business campaign should not begin by selling another SaaS dashboard.

## Wedge

```text
free audit
  ↓
find one expensive/repetitive pain
  ↓
migrate exactly that workflow into ChatGPT
  ↓
obtain only the permission required for it
  ↓
execute one real bounded case
  ↓
measure business/customer outcome
```

ChatGPT is the owner-facing interface. Our stack manages the consequential backend: permissions, company state, integrations, security, receipts and custom tools.

## Scarce asset

The scarce thing is not the automation code. It is the trusted delegated position:

- business-owner consent;
- private operating context;
- channel/account permissions;
- workflow history;
- customer/job outcomes;
- security/audit history;
- relationship/trust.

## Commercial model after proof

The initial migration can be free. Charge only after demonstrated value for ongoing:

- managed AI operations / consulting;
- security monitoring and incident handling;
- custom operational tools;
- communications/voice;
- accounting/admin workflows;
- priority support and continual optimization.

This avoids charging for software that is becoming abundant and instead charges for maintaining/improving consequential operation.
