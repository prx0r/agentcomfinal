# Roadmap

## Phase 0 — shipped in this scaffold
- common offer model
- RandomX reserve bid
- economic ranking
- privacy/policy model
- API + CLI

## Phase 1 — local miner
- hardware discovery
- one-click XMRig benchmark
- power measurement integrations
- P2Pool launcher/health checks
- historical local earnings DB
- thermal + idle-time controls

## Phase 2 — xmr.computer web
- CPU leaderboard (H/s/$, H/s/W)
- mine-vs-buy calculator
- historical XMR hashprice/difficulty
- production-cost curve
- used-hardware scanner
- server/compute deal scanner

## Phase 3 — market router
- signed adapter SDK
- sandboxed jobs
- real external compute adapters
- Qubic adapter
- settlement plugins
- switching-cost-aware optimizer

## Phase 4 — distributed network
- node reputation and remote attestations
- buyer job API
- XMR-denominated bidding
- workload replication / verification
- optional privacy-preserving worker discovery

## Phase 5 — agent-native XMR layer
- agent API/MCP tools for estimates, node deployment, mining status, payouts and education
- machine-readable Monero resource graph
- xmrbot.com media/education/assistant surface
